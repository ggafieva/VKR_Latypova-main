# Макеты страниц сайта Атнинской ЦРБ

Описание расположения блоков для 12+ страниц. Цветовая гамма: синий (#0066CC) + белый.

## 1. Главная (`/`)

```
┌─────────────────────────────────────────────┐
│  HEADER: логотип + навигация (10 пунктов)   │
├─────────────────────────────────────────────┤
│  HERO: заголовок | блок «Запись на приём»   │
├─────────────────────────────────────────────┤
│  Отделения (карточки 3 колонки)             │
├─────────────────────────────────────────────┤
│  Врачи (карточки с фото)                    │
├─────────────────────────────────────────────┤
│  Новости (3 карточки)                       │
├─────────────────────────────────────────────┤
│  FOOTER: адрес, разделы, автор              │
└─────────────────────────────────────────────┘
```

## 2. О больнице (`/about/`)

- Боковое меню слева
- Контент: история, миссия, структура (текстовые блоки)

## 3. Руководство (`/leadership/`)

- Карточки руководителей: фото + ФИО + должность + биография

## 4. Отделения (`/departments/`)

- Сетка карточек отделений
- Боковое меню со списком отделений

## 5. Карточка отделения (`/departments/<slug>/`)

- Описание отделения
- Список врачей
- Услуги отделения

## 6. Врачи (`/doctors/`)

- Фильтр по отделениям (sidebar)
- Сетка карточек врачей

## 7. Карточка врача (`/doctors/<slug>/`)

- Фото, ФИО, специальность
- Биография, образование
- Таблица расписания
- Кнопка «Записаться»

## 8. Пациентам (`/patients/`)

- Карточки информационных статей
- Список услуг

## 9. Контакты (`/contacts/`)

- 4 блока: адрес, телефоны, email, режим работы
- Блок карты

## 10. Обратная связь (`/feedback/`)

- Центрированная форма (имя, email, телефон, тема, сообщение, captcha)

## 11. Расписание (`/schedule/`)

- Sidebar со списком врачей
- Таблица: врач | специальность | день | время | кабинет

## 12. Личный кабинет (`/accounts/dashboard/`)

- Sidebar: профиль, заявки, запись, документы, уведомления
- Контент зависит от роли

## 13. Админ-панель (`/panel/`)

- Синий sidebar с 5 разделами
- Статистика + таблицы данных
- Кнопки скачивания DOCX/XLSX

## Адаптивность

| Breakpoint | Изменения |
|------------|-----------|
| < 768px | Гамбургер-меню, 1 колонка, горизонтальный скролл таблиц |
| 768–1024px | 2 колонки, sidebar под контентом → сбоку |
| > 1024px | 3 колонки, полная навигация с dropdown |
