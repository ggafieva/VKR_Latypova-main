# ГАУЗ «Атнинская центральная районная больница» — Веб-сайт (ВКР)

Веб-приложение на **Python 3.10+ / Django 4.2** для Государственного автономного учреждения здравоохранения «Атнинская центральная районная больница» (ГАУЗ).

## Возможности

- 12+ публичных страниц (главная, о больнице, руководство, отделения, врачи, расписание, пациентам, контакты, обратная связь, новости, услуги)
- 14 моделей базы данных (SQLite)
- 3 роли: Администратор, Врач, Пациент
- Кастомная панель администратора (5 разделов)
- Личный кабинет с 5+ страницами
- Генерация документов DOCX (расписание) и XLSX (отчёт по заявкам)
- Загрузка и управление файлами
- Адаптивная вёрстка (mobile-first)

## Быстрый старт

```bash
# Клонировать репозиторий
git clone <url> crb-atnya
cd crb-atnya

# Создать виртуальное окружение (рекомендуется)
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux/macOS

# Установить зависимости
pip install -r requirements.txt

# Применить миграции
python manage.py migrate

# Загрузить начальные данные
python manage.py load_initial_data

# Запустить сервер
python main.py
# или: python manage.py runserver
```

Сайт будет доступен по адресу: http://127.0.0.1:8000/

**Точка входа:** `main.py` в корне проекта (`python main.py`).

## Структура проекта

```
crb_project/          # Настройки Django
accounts/             # Пользователи, роли, личный кабинет
hospital/             # Публичная часть, модели больницы
panel/                # Кастомная админ-панель
documents/            # Генерация DOCX/XLSX
templates/            # HTML-шаблоны
static/               # CSS, JavaScript
mockups/              # Описание макетов страниц
media/                # Загруженные файлы
db.sqlite3            # База данных
```

## Панель администратора

Доступна по адресу `/panel/` (только для роли Администратор):

1. **Управление врачами** — `/panel/doctors/`
2. **Управление расписанием** — `/panel/schedules/` (+ скачивание DOCX)
3. **Управление пользователями** — `/panel/users/`
4. **Заявки обратной связи** — `/panel/feedbacks/` (+ отчёт XLSX)
5. **Управление файлами** — `/panel/files/`

## Генерация документов

- **DOCX** — выписка из расписания врача (кнопка в разделе «Расписание» админ-панели)
- **XLSX** — отчёт по заявкам обратной связи (кнопка в разделе «Заявки»)

Документы генерируются динамически через `HttpResponse` без сохранения на диск.
